# BRIDGE CURRICULUM RECORD
Branch: Information Technology
Pattern: 2023
Year: Second Year | Semester: III
Subject: Digital Electronics and Logic Design
Course Code: 2308206 | Course Type: MDM
Prerequisite: Fundamentals of Electronics Engineering

## Course Outcomes
- CO1: Simplify and Minimize a given Boolean expressions using K Map and Quine Mc-Cluskey method
- CO2: Design and implement combinational circuits using AND OR logic
- CO3: Design and implement combinational circuits using SSI and MSI logic
- CO4: Explain applications of Flip Flops
- CO5: Design and implement sequential logic circuits using Flip Flops.

## Course Contents
### Unit I — Logic Minimization Technique | CO1
Signed Magnitude, 1’s Complement, 2’s Complement, Binary Arithmetic, SOP and POS form, Don’t Care Conditions, Simplification of logical functions, K-map and Quine Mc-Cluskey Method.

### Unit II — Introduction to Combinational Circuits | CO2
Combinational Circuits, BCD, Excess-3, Gray code, Binary Code, Half-Adder, Full Adder, Half Subtractor, Full Subtractor, n bit Binary adder, Look ahead carry generator, 4 bit Binary Adder (IC 7483), BCD adder.

### Unit III — Combinational Logic Design | CO3
Multiplexers, Cascading multiplexers, ROM, PLA, PAL, Demultiplexers, Decoder, Boolean expression using Multiplexer and Demultiplexer, Comparators, Encoder, Parity generators and Checker.

### Unit IV — Introduction to Sequential Circuits | CO4
Combinational vs Sequential Circuits, SR/JK/D/T Flip-Flops, Preset & Clear, Master Slave JK, edge/level triggering, truth and excitation tables, shift registers, bidirectional shift register, ring counter, twisted ring counter, universal shift register.

### Unit V — Sequential Logic Design | CO5
Asynchronous counters, modulus, decade counter, synchronous up/down/up-down counters, state diagram, state assignment, state table, state reduction, design procedure, asynchronous vs synchronous counters, modulus-n counter using ICs 7490 and 74191, pseudo-random binary sequence generator, Moore & Mealy sequence detector.
