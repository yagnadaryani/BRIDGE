# BRIDGE CURRICULUM RECORD
Branch: Computer Engineering
Pattern: 2023
Year: Second Year | Semester: IV
Subject: Data Structures
Course Code: 2301212 | Course Type: PCC
Prerequisite: 2300118A: Computational Thinking and Problem Solving

## Course Outcomes
- CO1: Describe the fundamental concepts and terminology of data structures and algorithms, including arrays, linked lists, stacks, queues, Hashing and sorting algorithms
- CO2: Identify appropriate data structures such as Array, linked list, stack, queue and Hash Tables to solve a given problem
- CO3: Design and Develop an algorithms for array and linked list operations such as insertion, and deletion etc.
- CO4: Use stack and / or queue to solve the given problem
- CO5: Apply the hash table, concepts of collision resolution methods to solve the given problem

## Course Contents
### Unit I — Introduction to Data Structures and Algorithms | CO1, CO2, CO3
Data, data objects, data types, data structure, ADT, primitive/non-primitive, linear/nonlinear, static/dynamic, persistent/ephemeral structures. Algorithms, characteristics, analysis, space/time complexity, Big O. Arrays, memory representation/address calculation, insertion/deletion. Sorting stability, internal sorting, Quick, merge, shell, radix and external sorting.

### Unit II — Multidimensional Arrays and Memory Representation | CO1, CO2, CO3
Multidimensional arrays and memory representation. Single variable polynomial representation/evaluation/addition. Sparse matrix representation/addition/simple transpose/fast transpose. String operations using arrays.

### Unit III — Linked Lists | CO1, CO2, CO3
Linked list concept and ADT, sequential vs linked organization, realization using arrays/dynamic memory/header node, advantages/disadvantages, insert/delete/traverse/copy/reverse/concatenate/delete-list, linear/circular/doubly linked lists and operations, introduction to GLL.

### Unit IV — Stack & Queue | CO1, CO2, CO4
Stack ADT, array/linked representation, operations, multi-stacks, Polish notation, expression conversion/evaluation, function calls/returns, direct recursion. Queue ADT, array/linked realization, circular queue, deque, multi-queues, linked queue, scheduling and Josephus problem.

### Unit V — Hashing | CO1, CO2, CO5
Hash table concepts, hash function, bucket, collision, probe, synonym, overflow, open/closed hashing, perfect hash function, load density, full table, load factor, rehashing, operations/issues. Division, multiplication, extraction, mid-square, folding and universal hash functions. Open addressing/chaining and hash table overflow.
