# BRIDGE CURRICULUM RECORD
Branch: Information Technology
Pattern: 2023
Year: Second Year | Semester: III
Subject: Data Structure & Algorithm
Course Code: 2308202 | Course Type: PCC
Prerequisite: Discrete Mathematics

## Course Outcomes
- CO1: Select appropriate searching and sorting techniques in the application development.
- CO2: Apply appropriate linear data structures for problem solving and programming.
- CO3: Use appropriate tree data structures for problem solving and programming.
- CO4: Use appropriate graph data structures for problem solving and programming.
- CO5: Implement Abstract Data Type (ADT) and data structures for given application.

## Course Contents
### Unit I — Introduction to Data Structure | CO2
Concept of data, Data object, Data structure, Primitive and non-primitive, linear and Nonlinear, static and dynamic, persistent and ephemeral data structures, Definition of ADT. Frequency count, Time complexity, Space complexity, Big O, Ω and Θ notations. Single and multidimensional array and address calculation. Singly, Doubly and Circular Linked List with Create, Display, Search, Insert, Delete.

### Unit II — Searching and Sorting | CO1
Need of searching and sorting, internal and external sorting, sort stability. Linear and binary search algorithms, Fibonacci Series. Bubble, insertion, Quick, Merge, shell and comparison of all sorting methods. Analysis of Insertion sort, Quick Sort, binary search, hashing for Best, Worst and Average case.

### Unit III — Stack and Queue | CO2
Stack, implicit and explicit stack, stack as ADT using sequential and linked organization. Applications: recursion, infix to postfix/prefix conversion, postfix/prefix evaluation. Queue as ADT, implementation using array and linked organization, circular queue, double ended queue, priority queue.

### Unit IV — Tree | CO3
Trees and binary trees, terminology, expression tree, Binary tree as ADT, Binary search tree, recursive and non-recursive binary tree traversals, BST operations Insert/Search/Delete, level-wise display. Threaded Binary Tree, inorder/preorder/postorder, applications of trees.

### Unit V — Graph & Advance data Structure | CO4
Graph concepts and terminology, Graph as ADT, adjacency matrix/list, BFS, DFS, Prim’s and Kruskal’s minimum spanning tree algorithms, Dijkstra's shortest path, applications of Graph. Heap, Min/Max Heap, Heap sort, AVL Tree, Hash tables and scattered tables, hash function.
