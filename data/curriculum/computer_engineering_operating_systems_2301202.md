# BRIDGE CURRICULUM RECORD
Branch: Computer Engineering
Pattern: 2023
Year: Second Year | Semester: III
Subject: Operating systems
Course Code: 2301202 | Course Type: PCC

## Course Outcomes
- CO1: Illustrate the concept of systems software
- CO2: Illustrate the concept of process scheduling algorithms to solve scheduling problems
- CO3: Explain the concepts of deadlock and illustrate the techniques to detect, prevent and avoid the deadlock
- CO4: Demonstrate the use of page replacement algorithms for memory management
- CO5: Explain the concept of I/O management techniques
- CO6: Demonstrate the use of Linux commands and basic shell utilities

## Course Contents
### Unit I — Introduction to systems programming | CO1
Introduction, Components of System Software, Text editors, Loaders, Linkers, Assemblers, Macro processors, Compilers, Debuggers, Elements of Assembly Language Programming, A Simple Assembly Scheme, Pass Structure of Assemblers, Design of Two Pass Assembler, Single pass Assembler.

### Unit II — Process management | CO2
Introduction to Operating Systems. Types: Batch, Time-sharing, Network, Distributed and real-time. Process concept, Process Control Block, Process state diagram, Inter-process communication. First come first serve, Shortest job first, Round robin, Priority-based scheduling. Multi-core programming, Multithreading models, Implicit threading, Threading issues.

### Unit III — Process coordination | CO3
Critical-section problem, Peterson’s solution, Synchronization hardware, Mutex locks, Semaphores. Producer-consumer, Reader/writer, Dining philosopher. Deadlock characterization, handling, prevention, avoidance, detection and recovery.

### Unit IV — Memory Management | CO4
Fixed and dynamic partitioning, First fit, Best fit, Worst fit, Swapping, page table, Segmentation, Demand paging, FIFO/Optimal/LRU page replacement, translation lookaside buffer.

### Unit V — I/O management and Introduction to Linux | CO5, CO6
I/O devices, FCFS/SSTF/SCAN/C-SCAN disk scheduling, Bash shell scripting, Linux features, file systems/directories, pwd/cd/ls/cat/rm/cp/mkdir, tr/sed/grep/egrep/awk, file access rights.
