# BRIDGE CURRICULUM RECORD
Branch: Computer Engineering
Pattern: 2023
Year: Second Year | Semester: III
Subject: Digital Electronics and Logic Design
Course Code: 2301206 | Course Type: MDM
Prerequisite: 2300107A: Fundamentals of Electronics Engineering

## Course Outcomes
- CO1: Solve the problem of minimization using K Map and Quine Mc-Clusky method of Boolean expression
- CO2: Build combinational circuits using AND-OR logic
- CO3: Build combinational circuits using SSI and MSI logic
- CO4: Explain applications of Flip Flops, registers and shift registers
- CO5: Develop sequential logic circuits using Flip Flops and MSI logic

## Course Contents
### Unit I — Logic Minimization Techniques | CO1
Signed binary representation, 1’s/2’s complement, binary arithmetic, SOP/POS Boolean expressions, don’t-care conditions, K-map and Quine Mc-Clusky minimization.

### Unit II — Introduction to Combinational Circuits | CO2
Combinational circuits, BCD, Excess-3, Gray code, half/full adder, half/full subtractor, universal adder/subtractor, 4-bit binary adder IC 7483, look-ahead carry generator, BCD adder.

### Unit III — Combinational Logic Design | CO3
Multiplexers, cascading multiplexers, demultiplexers, encoder, decoder, Boolean expression implementation using multiplexer/demultiplexer, comparators, parity generator/checker, ROM, PLA, PAL.

### Unit IV — Introduction to Sequential Circuits | CO4
Combinational vs sequential circuits, SR/clocked-SR/JK/master-slave JK/T/D flip-flops, preset/clear, edge/level triggering, truth/excitation tables, registers, shift registers, bidirectional shift register, ring/twisted-ring/universal shift registers.

### Unit V — Sequential Logic Design | CO5
Synchronous/asynchronous counters, modulus, decade counter, up/down/up-down counters, state diagram/assignment/table/reduction, design procedure, sequence generator, sequence detector with/without overlap.
